# Drop Noah's photos here 📸

Add up to 3 photos of Noah with these exact filenames:

- `noah1.jpg`
- `noah2.jpg`
- `noah3.jpg`

They'll be used both as small badges on the board's Noah squares and
for the "gobble" animation that pops up whenever the player lands on
one. The game cycles through whichever ones you provide.

**No photos yet?** No problem — the game already works without them and
just shows a 😋 emoji instead. Add photos any time and it'll pick them up
automatically, no code changes needed.

Tips:
- Square-ish crops work best (they're displayed in a circle).
- JPG or PNG both work — just keep the `.jpg` extension in the filename,
  or edit the `NOAH_IMAGES` list in `script.js` if you use `.png`.
- Keep file sizes reasonably small (under ~500KB each) so the game loads fast.
